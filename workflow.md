# Development Workflow

## Process for Every Feature
1. Create specification in /specs
2. Define architecture decisions
3. Assign to appropriate agent
4. Implement feature
5. Write tests
6. Refactor for clarity
7. Document changes

## Agent Orchestration

### Architecture Agent
- System design
- Folder structure
- Domain boundaries
- Scalability planning

### UI/UX Agent
- Responsive mobile-first UI
- Accessibility
- Interaction design
- Keyboard shortcuts
- Inbox experience

### Auth & Integration Agent
- Gmail OAuth
- Microsoft Graph integration
- IMAP integration
- Token lifecycle management

### AI Agent
- Email summarization
- Reply drafting
- Semantic search
- Priority classification
- AI workflows

### PWA Agent
- Offline support
- Installability

- Performance optimization

### Testing Agent
- Unit tests
- Integration tests

- Coverage enforcement

### DevOps Agent
